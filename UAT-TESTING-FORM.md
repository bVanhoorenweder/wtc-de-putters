## 🎯 Wie Uitnodigen voor Testing

### Ideale Test Groep (10-20 personen)

**Diversiteit is belangrijk:**

1. **Per groep** (A/B/C/D)
   - 2-3 personen uit elke fietsgroep
   - Mix van beginnende en ervaren leden

2. **Per leeftijd**
   - Enkele jongere leden (< 40)
   - Enkele oudere leden (60+)
   - Midden groep (40-60)

3. **Per tech-niveau**
   - 2-3 tech-savvy mensen (vinden bugs makkelijk)
   - 2-3 minder technische mensen (testen gebruiksvriendelijkheid)
   - Rest: gemiddeld

4. **Per apparaat**
   - Vraag specifiek aan iPhone gebruikers
   - Vraag specifiek aan Android gebruikers
   - Vraag aan tablet gebruikers
   - Vraag aan desktop gebruikers

5. **Specifieke rollen**
   - 1-2 bestuursleden
   - 1 nieuwe lid (< 6 maanden)
   - 1 potentieel nieuw lid (kent site niet)

## 📊 Na het Testen - Data Analyse

### Prioritering van Feedback

**KRITISCH (Fix voor live):**
- Broken links/buttons
- Mobiel layout crashes
- Onleesbare tekst
- Ontbrekende cruciale info (contact, lidmaatschap)
- Security issues

**BELANGRIJK (Fix indien mogelijk):**
- Verwarrende navigatie
- Trage laadtijd
- Design inconsistenties
- Content fouten/typos

**NICE TO HAVE (Fase 2):**
- Extra features
- Design tweaks
- Extra content
- Kleine verbeteringen

### Bug Tracking

Maak een simpele lijst in Excel/Google Sheets:

| Bug/Issue | Wie meldde | Apparaat | Prioriteit | Status |
|-----------|-----------|----------|------------|--------|
| Menu werkt niet op iPhone | Jan | iPhone 12 | KRITISCH | To Fix |
| Foto laadt traag | Mieke | Android | Belangrijk | In Progress |
| etc. | | | | |

## ✅ Go/No-Go Decision Criteria

**Website kan LIVE als:**
- [ ] Geen kritieke bugs meer
- [ ] 80%+ testers zijn tevreden (score 7+/10)
- [ ] Alle pagina's werken op mobiel/desktop
- [ ] Alle links werken
- [ ] Laadtijd < 3 seconden
- [ ] Feedback positief tot neutraal
- [ ] Bestuur akkoord

**Niet live als:**
- [ ] Veel kritieke bugs
- [ ] Veel negatieve feedback
- [ ] Grote design problemen
- [ ] Content fouten
- [ ] Mobiel werkt niet goed

## 🆘 Tips voor Goede Testing

1. **Wees specifiek in je vragen** - "Werkt het menu?" vs "Kun je het hamburger menu openen op je telefoon?"

2. **Test zelf eerst grondig** - Fix obvious bugs voor je anderen vraagt

3. **Diverse test groep** - Verschillende leeftijden, tech-niveaus, apparaten

4. **Geef duidelijke instructies** - Link naar site + formulier, wat je verwacht

5. **Deadline stellen** - Anders blijft het hangen

6. **Blijf beschikbaar** - Voor vragen tijdens het testen

7. **Handel feedback snel af** - Laat zien dat je luistert

8. **Communiceer wijzigingen** - "Dankzij jullie feedback hebben we X aangepast"
